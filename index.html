About LinkShort

LinkShort is a privacy-first local URL shortener. No ads, no external servers. Extensions run fully in your browser and are disabled by default.

  • AI Assistant — Beta guided link creation (opt-in).
  • Identicon generator — visual identity (helper only).
  • Bulk operations, export/import and CSV analytics — manual actions only.

Version 1.4 — experimental features clearly labeled BETA.
