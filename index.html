About LinkShort

LinkShort is local-only. It stores all mappings in your browser's LocalStorage. There are no servers, no database, and no telemetry.

Short links are served through the configured base domain using the query parameter ?c=IDENTIFIER.

In HTTP Subdomain Mode, the identifier (slug) is taken from the host label before the first dot of the provided hostname (for example mywebsite from mywebsite.server.com).
