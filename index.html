About LinkShort

LinkShort is a privacy-first local URL shortener. No ads, no external servers. Extensions run fully in your browser.

  • AI Assistant — Beta guided link creation.
  • Identicon generator — unique visual for each link.
  • Bulk operations, export/import and CSV analytics.

Version 1.4 — experimental features are clearly labeled Beta.
