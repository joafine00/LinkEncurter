About LinkShort

LinkShort is a privacy-first, ad-free link shortener that works entirely in your browser.

No databases, no servers, no tracking — everything runs in LocalStorage.

You can create up to 10 links per browser session.

Each short link uses your configured base domain, for example:

https://d0linkname.vercel.app/?c=CODE

If you use HTTP (Subdomain Mode), it simulates a non-secure or local network environment — useful for testing or non-DNS hosting setups.
